# 🚀 90 Days of Engineering Growth

> Building the skills, discipline and engineering mindset required to become a strong Software and AI Engineer.

## 🎯 Mission Overview

- Duration: 90 Days
- AI learning commitment: 1 hour daily
- Learning tracks: 5
- Goal: Become an independent problem solver and capable AI engineer.

## 📚 Five Learning Tracks

| Track | Focus Areas |
|---|---|
| CS Core | OOP, DBMS, OS, CN, SQL, System Design |
| DSA | Data Structures, Algorithms, Problem Solving |
| GATE CSE | Syllabus, PYQs, Revision, Mock Tests |
| AI Engineering | Prompt Engineering, LLMs, RAG, Agents, Evaluation |
| Projects | Development, Testing, Git, Deployment |

## 🔍 Engineering Principles

1. Understand before implementing.
2. Never blindly trust AI-generated answers.
3. Verify code through testing.
4. Focus on consistency.
5. Build real-world projects.
6. Document mistakes and learn from them.
7. Take ownership of every solution.

## 🏁 Final Goal

Become stronger in CS fundamentals, DSA, GATE CSE, AI Engineering and practical software development.

**Learning in public. Building consistently. Improving every day.** 🚀
